
# LMSProject

Учебный проект системы управления курсами и уроками на Django REST Framework.

## Возможности

- Собственная модель пользователя на основе AbstractBaseUser.
- Авторизация пользователей по email.
- Дополнительные поля пользователя: телефон, город, аватар.
- Модели Course и Lesson со связью один ко многим.
- CRUD для курсов через ModelViewSet.
- CRUD для уроков через Generic API Views.
- Административная панель Django.
- Автоматические тесты API и моделей.

## Технологии

- Python
- Django
- Django REST Framework
- SQLite
- Pillow
- Ruff

## Установка

Клонировать репозиторий:

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd LMSProject
```

Создать виртуальное окружение:

```bash
python -m venv .venv
```

Активировать окружение в Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Применить миграции:

```bash
python manage.py migrate
```

Запустить сервер:

```bash
python manage.py runserver
```

## API

### Курсы

| Метод | URL | Описание |
|---|---|---|
| GET | /api/courses/ | Список курсов |
| POST | /api/courses/ | Создание курса |
| GET | /api/courses/{id}/ | Получение курса |
| PUT/PATCH | /api/courses/{id}/ | Обновление курса |
| DELETE | /api/courses/{id}/ | Удаление курса |

### Уроки

| Метод | URL | Описание |
|---|---|---|
| GET | /api/lessons/ | Список уроков |
| POST | /api/lessons/create/ | Создание урока |
| GET | /api/lessons/{id}/ | Получение урока |
| PUT/PATCH | /api/lessons/{id}/update/ | Обновление урока |
| DELETE | /api/lessons/{id}/delete/ | Удаление урока |

## Дополнительная функциональность LMS

### Курсы и уроки

Сериализатор курса дополнительно возвращает:

- `lessons_count` — количество уроков курса через SerializerMethodField.
- `lessons` — список уроков с вложенными данными.

### Платежи

Реализована модель Payment со следующими полями:

- Пользователь
- Дата оплаты
- Оплаченный курс или урок
- Сумма оплаты
- Способ оплаты (наличные или перевод на счёт)

### Заполнение тестовыми данными

Для создания тестовых курсов, уроков и платежей выполните:

```bash
python manage.py createsuperuser
python manage.py load_payments
```

Команда `load_payments` создаёт пять примеров платежей.

### API платежей

GET `/api/payments/`

Поддерживаются следующие параметры:

| Параметр | Пример | Описание |
|---|---|---|
| `ordering` | `payment_date` | Сортировка по возрастанию даты |
| `ordering` | `-payment_date` | Сортировка по убыванию даты |
| `course` | `1` | Фильтрация по курсу |
| `lesson` | `1` | Фильтрация по уроку |
| `payment_method` | `cash` | Оплата наличными |
| `payment_method` | `transfer` | Перевод на счёт |

Параметры можно комбинировать.

Пример:

`/api/payments/?payment_method=transfer&ordering=payment_date`

### История платежей пользователя

GET `/api/users/{id}/`

Профиль возвращает данные пользователя и полную историю
платежей с вложенной информацией о курсах и уроках.
