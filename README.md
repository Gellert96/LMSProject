# LMSProject

LMSProject — учебный REST API для системы управления онлайн-обучением, разработанный на Django и Django REST Framework.

Проект позволяет управлять курсами, уроками, пользователями и платежами. Реализованы JWT-авторизация, разграничение прав доступа и группа модераторов.

## Технологии

- Python
- Django
- Django REST Framework
- Simple JWT
- Django Filter
- SQLite
- Ruff
- Django Test Framework

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/Gellert96/LMSProject.git
cd LMSProject
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

Активация в Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 3. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

### 4. Применение миграций

```bash
python manage.py migrate
```

### 5. Создание группы модераторов

```bash
python manage.py create_moderators
```

Команда создаёт группу `moderators`, если она ещё не существует.

Добавить пользователя в группу можно через Django Admin. Для доступа к административной панели необходимо создать суперпользователя:

```bash
python manage.py createsuperuser
```

### 6. Запуск сервера

```bash
python manage.py runserver
```

API будет доступен по адресу:

`http://127.0.0.1:8000/api/`

## Регистрация и JWT-авторизация

Регистрация пользователя доступна без авторизации.

**POST `/api/register/`**

Пример запроса:

```json
{
  "email": "student@example.com",
  "password": "SecurePassword123!"
}
```

Получение JWT-токенов:

**POST `/api/token/`**

```json
{
  "email": "student@example.com",
  "password": "SecurePassword123!"
}
```

При успешной авторизации сервер возвращает `access` и `refresh` токены.

Обновление access token:

**POST `/api/token/refresh/`**

Для обращения к защищённым эндпоинтам необходимо передавать заголовок:

```http
Authorization: Bearer <access_token>
```

## Основные эндпоинты

### Пользователи

| Метод | URL | Описание |
|---|---|---|
| POST | `/api/register/` | Регистрация пользователя |
| GET | `/api/users/` | Список публичных профилей |
| GET | `/api/users/{id}/` | Просмотр профиля |
| PUT / PATCH | `/api/users/{id}/` | Редактирование своего профиля |
| DELETE | `/api/users/{id}/` | Удаление своего профиля |

### Курсы

| Метод | URL | Описание |
|---|---|---|
| GET | `/api/courses/` | Список доступных курсов |
| POST | `/api/courses/` | Создание курса |
| GET | `/api/courses/{id}/` | Просмотр курса |
| PUT / PATCH | `/api/courses/{id}/` | Редактирование курса |
| DELETE | `/api/courses/{id}/` | Удаление курса |

### Уроки

| Метод | URL | Описание |
|---|---|---|
| GET | `/api/lessons/` | Список доступных уроков |
| POST | `/api/lessons/create/` | Создание урока |
| GET | `/api/lessons/{id}/` | Просмотр урока |
| PUT / PATCH | `/api/lessons/{id}/update/` | Редактирование урока |
| DELETE | `/api/lessons/{id}/delete/` | Удаление урока |

### Платежи

**GET `/api/payments/`**

Поддерживаются фильтрация по курсу, уроку и способу оплаты, а также сортировка по дате платежа.

Например:

```http
GET /api/payments/?payment_method=transfer&ordering=-payment_date
```

Пользователь получает доступ только к собственной истории платежей.

## Разграничение прав доступа

### Обычный пользователь

- Может создавать курсы и уроки.
- Автоматически становится владельцем созданных объектов.
- Может просматривать, редактировать и удалять собственные курсы и уроки.
- Не может управлять чужими курсами и уроками.
- Может создавать уроки только внутри собственных курсов.
- Может изменять и удалять собственный профиль.
- Может просматривать публичные данные других пользователей.

### Модератор

Пользователь из группы `moderators`:

- Может просматривать любые курсы и уроки.
- Может редактировать любые курсы и уроки.
- Не может создавать курсы и уроки.
- Не может удалять курсы и уроки.

Для реализации ограничений используются пользовательские классы разрешений `IsModerator` и `IsOwner`.

### Защита пользовательских данных

При просмотре чужого профиля не раскрываются пароль, электронная почта, фамилия и история платежей.

Для изменения и удаления чужих профилей доступ запрещён.

## Тестирование

Запуск всех автоматических тестов:

```bash
python manage.py test
```

В проекте реализованы 53 автоматических теста, охватывающих:

- Модели курсов и уроков.
- CRUD курсов и уроков.
- Сериализацию вложенных данных.
- Права владельцев и модераторов.
- Регистрацию и JWT-авторизацию.
- Доступ к профилям пользователей.
- Фильтрацию и сортировку платежей.
- Конфиденциальность платёжной информации.

Проверка кода:

```bash
ruff check .
```

Проверка конфигурации Django:

```bash
python manage.py check
```

Проверка состояния миграций:

```bash
python manage.py makemigrations --check --dry-run
```
